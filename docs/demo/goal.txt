Build a beautiful interactive Mandelbrot explorer entirely on this Android device. Use Termux to install Python if needed, create a self-contained HTML/JavaScript canvas app in ~/fractal-lab with a dark interface, vivid fractal colors, tap-to-zoom and Reset controls. Start a Python HTTP server bound only to 127.0.0.1 on port 8000, open Chrome at http://127.0.0.1:8000, verify the fractal renders, zoom into it twice and reset. You may install Python from the configured official Termux repository, write files only in ~/fractal-lab and run this local server. No external services or code dependencies. Use input_text for terminal commands and heredocs. Keep code compact. Finish on the rendered fractal with the keyboard hidden.
